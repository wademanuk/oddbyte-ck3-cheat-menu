# Changelog

## 1.6.0

- Adds legitimacy adjustments, dread adjustments/exact values and tyranny removal.
- Adds language learning from Other's culture and shared cultural acceptance controls.
- Adds individual dynasty legacy unlocks, preserving track order, native eligibility and renown.
- Offers the required trait choice when unlocking legacies such as Architected Ancestry.
- Adds guardian assignment/removal for available people at the same court and five childhood education focuses.
- Adds alliance creation/removal with checks for existing alliances, enemies and liege chains.
- Includes the new actions in Search, Favourites and confirmation reviews that retain the original targets.
- Preserves the local Steam Workshop publication ID during a backed-up installation upgrade.
- Tightens native error-log detection and isolates destructive test fixtures from boost-removal checks.

## 1.5.2

- Introduces **Oddbyte — CK3 Cheat Menu** as the public name.
- Adds a public download package, installation instructions and current feature guide.
- Separates player documentation from build/test instructions.
- Makes the game-data and local installation paths configurable for development.
- Retains gameplay features, installation ID and save-variable names from 1.5.1.

## 1.5.1 gameplay fixes

- Faith matching copies the exact rite; created characters inherit their employer's rite.
- Expired pins and character references no longer silently redirect selection.
- Trait additions respect native age limits; locked tenets require their DLC.
- Artifact creation supplies native material/visual context, with a base-game crown fallback.
- Higher-title transfers require an already landed recipient; counties can still go to unlanded people.
- Renown/development reviews retain their original dynasty/county and reject changed targets.
- Trait XP actions identify the trait and track in Search and Favourites.
